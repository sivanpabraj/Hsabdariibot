# ربات حسابداری شخصی (حرفه‌ای)

سیستم دفترکل برای مدیریت **بانک‌ها، کارت‌ها، شماره حساب، شبا، موجودی اولیه** و ثبت واریز/برداشت با گزارش ماهانه شمسی.

## امکانات سطح بالا

- تعریف حساب بانکی / کارت / نقد / کیف پول
- انتخاب بانک‌های رایج ایران + بانک سفارشی
- ذخیره امن‌نمایی‌شده شماره کارت، حساب و شبا با اعتبارسنجی
- موجودی اولیه + محاسبه موجودی لحظه‌ای
- ثبت دستی و ثبت با رسید (Gemini)
- دسته‌بندی مخارج (بنزین، منزل، اجاره، آب/برق/گاز و …)
- گزارش ماهانه به‌تفکیک دسته و حساب

## دیتابیس

SQLite با ساختار دفترکل:

- `banks` — کاتالوگ بانک
- `bank_accounts` — حساب‌ها (کارت/شبا/موجودی اولیه)
- `ledger_entries` — اسناد مالی
- مهاجرت خودکار از نسخه قبلی

## راه‌اندازی

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# BOT_TOKEN را از @BotFather در .env بگذارید
python diagnose.py    # بررسی توکن و webhook
python run.py         # فقط یک نمونه باید اجرا باشد
```

`.env` را commit نکنید.

## دستورهای مهم

| دستور | کار |
|---|---|
| `/newbankaccount` | ساخت حساب/کارت با بانک و موجودی اولیه |
| `/accounts` | لیست حساب‌ها و موجودی |
| `/deposit` `/withdraw` | ثبت گردش |
| `/receipt` | ثبت با رسید |
| `/report` | گزارش ماه |
| `/ping` | تست آنلاین بودن |

اگر ربات جواب نداد:

1. `python diagnose.py` را اجرا کنید
2. فقط **یک** `python run.py` روشن باشد (نمونه‌های تکراری همدیگر را قطع می‌کنند)
3. در تلگرام `/ping` بعد `/start` بزنید
